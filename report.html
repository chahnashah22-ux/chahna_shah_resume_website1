3. Design System & Typographic Details

The 60-30-10 Color Theory

The color system is organized into explicit CSS custom variables:

  • 60% Canvas (#faf9f6): Warm, low-fatigue background reminiscent of premium unbleached stock.
  • 30% Surface (#ffffff, #f2f1ec): Architectural surface panels divided by 1px hairlines.
  • 10% Accent (#2f4838): Botanical Forest Sage reserved strictly for CTAs, active filters, and anchors.

Typographic Precision

Typography combines editorial warmth with analytical rigor:

  • text-wrap: balance: Automatically balances multi-line headlines, eliminating lone orphan words.
  • tabular-nums: Forces monospace numeric alignment across dates (e.g. 2026 – Present) and percentages.
  • clamp(2.75rem, 6vw, 5.25rem): Smooth fluid font sizing across mobile, tablet, and ultra-wide screens.

4. HTML5 & Vanilla JavaScript Architecture

Client-Side Category Filtering

Zero-dependency JavaScript listens to filter buttons (#edu-filters, #skill-filters) and updates card visibility using data-filter matches. Screen-reader states are updated in real-time via aria-pressed.

Interactive Case Study Modal Dialog

Clicking on Chaah Jewels, Social Mobility Documentary, or Art & Design opens a structured modal with key focus areas and takeaways. Includes background scroll lock and keyboard Escape handling.

5. Autonomous Print & PDF Engine (@media print)

A dedicated print stylesheet ensures that anyone visiting the site can immediately export a professional executive CV by printing to PDF (Cmd + P) or clicking "Print Resume":

  • Interface Stripping: Navigation bar, action buttons, filter pills, and footers are suppressed via .no-print { display: none !important; }.
  • Executive Print Header: The .print-only-bar displays the candidate's name, degree tracks, and contact email (chahnashah22@gmail.com).
  • Pagination Control: break-inside: avoid ensures individual education cards and project descriptions are never awkwardly split across page margins.
